# 02 : MÉCANISME : RÉGIMES

Un **régime (environnement statistique ou économique relativement distinct)** est utile lorsqu'une règle se comporte différemment selon le contexte.

```text
même stratégie
 ├─ tendance + volatilité forte → comportement A
 └─ range + volatilité faible   → comportement B
```

Un régime doit être défini par des variables observables, pas par le nom du marché après coup.
