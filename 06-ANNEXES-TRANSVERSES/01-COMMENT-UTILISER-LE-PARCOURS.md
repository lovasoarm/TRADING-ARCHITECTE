# COMMENT UTILISER LE PARCOURS

## Ne lis pas tout

Le dépôt est un réseau. Le fil normal est :

```text
START HERE → PROGRESSION → MODULE → LEÇON → CHALLENGE → BOSS → PORTAGE → PONT
```

`90` = rappel. `95` = challenge. `96` = Boss. `99` = transfert. `99A` = passage.

## Guide anti-friction

**Je ne comprends pas un terme** → `07-GLOSSAIRE.md`.

**Je ne sais plus quoi faire** → `PROGRESSION.md`.

**Je suis bloqué** → retourne au dernier critère non prouvé, pas au début du dépôt.

**Je crois un graphique trop vite** → reviens à la Charte et cherche le contre-exemple.
