## Comment travailler ce module

**Question directrice :** Chaque notion doit relier vocabulaire, mécanisme, mesure et pratique.

| Étape | Ce que tu produis | Contrôle personnel |
|---|---|---|
| 1. Lire | une carte de mécanisme | peux-tu l’expliquer sans le jargon ? |
| 2. Manipuler | un exemple chiffré ou une petite simulation | tes nombres retombent-ils ? |
| 3. Contredire | un contre-exemple | sais-tu dire quand le mécanisme cesse de tenir ? |
| 4. Construire | un artefact reproductible | quelqu’un d’autre peut-il le refaire ? |
| 5. Défendre | une conclusion + limites | que réponds-tu à l’objection la plus forte ? |

### Sortie attendue

Ne cherche pas à « finir le dossier ». Cherche à laisser derrière toi une **preuve inspectable** : tableau, calcul, code, expérience, journal ou décision justifiée.

### Matériel minimum

- un éditeur Markdown ;
- Python 3.x pour les modules numériques ;
- un petit jeu de données local ;
- un journal des hypothèses et résultats.

### Références de départ

Ce module s’appuie notamment sur les notions et travaux déjà recensés dans le corpus de recherche : microstructure, biais de validation, risques, facteurs et prospective. Les références précises sont reprises dans les leçons qui suivent afin que la source soit attachée au raisonnement plutôt que cachée dans une annexe.
