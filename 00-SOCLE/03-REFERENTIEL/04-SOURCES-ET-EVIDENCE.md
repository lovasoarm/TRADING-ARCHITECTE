# 04 — SOURCES ET ÉVIDENCE

## Hiérarchie pratique

```text
source primaire / papier / régulateur
          ↓
reproduction indépendante
          ↓
données ouvertes / méthodologie
          ↓
analyse secondaire sérieuse
          ↓
article de synthèse
          ↓
post / vidéo / capture
```

Une source populaire peut être utile pour générer une hypothèse. Elle ne suffit pas à la valider.

## Une affirmation exige au moins

- ce qui est affirmé ;
- sur quelles données ;
- sur quelle période ;
- avec quels coûts ;
- avec quelles limites ;
- quelle preuve contraire existe.
