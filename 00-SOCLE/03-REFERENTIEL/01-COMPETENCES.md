# 01 : COMPÉTENCES

## Niveaux

**L0 : vocabulaire** : définir simplement.

**L1 : observation** : décrire sans inventer la causalité.

**L2 : mesure** : calculer une grandeur correctement.

**L3 : hypothèse** : proposer une explication falsifiable.

**L4 : construction** : coder ou formaliser une règle reproductible.

**L5 : validation** : tester hors échantillon et après coûts.

**L6 : pilotage** : gérer portefeuille, risque et exécution.

**L7 : épreuve** : casser le système volontairement.

**L8 : architecture** : choisir les invariants et les contrôles.

**L9 : défense** : soutenir ou abandonner une thèse sous contradiction.
