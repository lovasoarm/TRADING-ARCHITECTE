# 03 : INTEMPOREL VS PÉRISSABLE

## Plutôt intemporel

```text
incitation
probabilité
microstructure
gestion du risque
coûts de transaction
biais de validation
réplication
```

## Plus périssable

```text
nom d'une API
interface d'un broker
modèle de langage précis
règle réglementaire précise
bibliothèque Python
outil de charting
```

## Règle de conception

L'outil change ? Le noyau doit survivre.

C'est pourquoi la prospective 2035+ vise des **capacités transférables** (gouvernance, architecture, risque, données), plutôt qu'un inventaire de boutons.
