# 05 — COMMENT LIRE UNE LEÇON

Chaque leçon possède au moins cinq couches.

```text
1. Pourquoi ça compte
2. Vocabulaire simple
3. Mécanisme
4. Exemple / expérience
5. Limite / transfert
```

## Règle anti-lecture passive

Après chaque section, ferme le fichier et réponds :

1. Qu'est-ce que je peux expliquer ?
2. Qu'est-ce que je peux mesurer ?
3. Qu'est-ce qui pourrait me contredire ?

## Quand un terme est trop dense

Ne quitte pas le parcours. Ouvre d'abord le glossaire du [REFERENTIEL](../03-REFERENTIEL/README.md).

## Quand une équation fait peur

Cherche d'abord :

```text
grandeur → unité → intuition → rôle dans une décision
```

L'équation vient ensuite.
