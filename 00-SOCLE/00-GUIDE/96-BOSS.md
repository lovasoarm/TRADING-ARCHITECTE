# 96 : BOSS DU GUIDE

Un faux expert te montre trois captures de trades gagnants et affirme connaître le marché.

Tu dois :

1. identifier ce qui est observable ;
2. séparer résultat et mécanisme ;
3. demander quelles données manquent ;
4. proposer une expérience minimale ;
5. définir le résultat qui te ferait changer d'avis.

## Refus automatique

```text
« ça marche sur TradingView » = insuffisant
« un trader célèbre le dit » = insuffisant
« l'IA l'a trouvé » = insuffisant
« j'ai gagné trois fois » = insuffisant
```

## Passage

```text
Construire → Expliquer → Justifier → Défendre → PREUVE
```
