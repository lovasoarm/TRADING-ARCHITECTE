# 03 — SETUP SANS CAPITAL

## Matériel minimal

- un éditeur Markdown ;
- un terminal ;
- Python 3.x pour la partie quantitative ;
- Git facultatif au début, recommandé ensuite ;
- un tableur facultatif comme outil de contrôle, jamais comme preuve unique.

## Sécurité de départ

```text
APPRENDRE
   ↓
papier / simulation
   ↓
reproductibilité
   ↓
seulement ensuite : décision sur capital réel
```

Le cursus ne demande pas d'ouvrir un compte de trading réel.

## Dossier de travail conseillé

```text
trading-architecte-lab/
├─ notes/
├─ hypotheses/
├─ data/
├─ experiments/
├─ reports/
└─ proofs/
```

## Première règle

Ne mélange jamais :

`donnée brute` / `donnée transformée` / `résultat` / `interprétation`.

Cette séparation protège contre les erreurs invisibles.
