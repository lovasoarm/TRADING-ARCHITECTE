# 02 — PRÉREQUIS ZÉRO

**Aucun prérequis caché.**

Si tu sais lire, compter, copier/coller un fichier et écrire quelques phrases, tu peux commencer.

## Auto-test

| Question | Oui/Non |
|---|---|
| Je sais ce qu'est un pourcentage | |
| Je sais lire un tableau simple | |
| Je peux suivre une consigne en 5 étapes | |
| Je peux garder une trace datée de mon travail | |
| J'accepte de dire « je ne sais pas encore » | |

Tout « non » est acceptable. Ce dépôt donne le détour exact.

## Pas nécessaire au départ

```text
≠ capital réel
≠ broker
≠ diplôme de finance
≠ Python avancé
≠ mathématiques universitaires
≠ connaissance de 50 indicateurs
```

## À acquérir plus tard

```text
probabilités → statistiques → Python → données → validation → portefeuille → exécution
```
