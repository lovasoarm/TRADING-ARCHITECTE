# 00-GUIDE — START HERE

Ce dossier existe pour une raison simple : **ne pas confondre expertise du domaine et capacité à apprendre le domaine**.

Tu peux arriver sans savoir :

- ce qu'est un broker (intermédiaire qui transmet/exécute les ordres) ;
- ce qu'est un spread (écart entre prix acheteur et vendeur) ;
- ce qu'est un rendement (variation relative de valeur) ;
- ce qu'est Python ;
- ce qu'est un backtest (simulation historique d'une règle) ;
- pourquoi une belle courbe n'est pas une preuve.

Le parcours t'introduit progressivement à chacun de ces mots.
