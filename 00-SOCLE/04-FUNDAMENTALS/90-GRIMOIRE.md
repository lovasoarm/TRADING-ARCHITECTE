# 90 : GRIMOIRE FOUNDATIONS

```text
Rendement ≠ profit garanti
Volatilité ≠ drawdown
Levier ≠ edge
Marge ≠ perte maximale
Liquidité ≠ absence de risque
Backtest ≠ futur
Corrélation ≠ causalité
```

Avant toute équation :

`grandeur → unité → intuition → formule → exemple → limite`.
