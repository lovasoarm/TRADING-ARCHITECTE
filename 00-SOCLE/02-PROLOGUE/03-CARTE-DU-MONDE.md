# 03 : CARTE DU MONDE

```text
SOCLE
  ├─ débutant / vocabulaire / maths / mécanique
  └─ méthode de travail
        ↓
CADRAGE
  └─ hypothèses / marché / comportements / régimes
        ↓
CONSTRUCTION
  └─ données / stratégie / backtest / validation
        ↓
PILOTAGE
  └─ portefeuille / risque / exécution / opérations
        ↓
ÉPREUVE
  └─ red team / réplication / incident / stress
        ↓
MAÎTRISE
  └─ recherche / IA gouvernée / 2035+ / thèse
```

## Ne confonds pas les rôles

Le **SOCLE** t'apprend les rails. Le **CORE** t'apprend à construire. L'**ÉPREUVE** vérifie si ça tient.
