# 02 — HYPOTHÈSE FALSIFIABLE

## CARTE VISUELLE

```text
question
  ↓
mécanisme
  ↓
mesure
  ↓
expérience
  ↓
contre-exemple
  ↓
décision
```

Forme minimale :

`Je crois X parce que Y ; si X est faux, j'observerai Z.`

Écris-la **avant** de regarder le résultat si possible.

Cela limite le réécriture opportuniste du récit.
