# 05 : REPRODUCTIBILITÉ

## CARTE VISUELLE

```text
OBSERVE
   ↓
FORMULE
   ↓
CONSTRUIS
   ↓
TESTE
   ↓
MESURE
   ↓
CASSE
   ↓
RÉVISE
   ↺
```

Un résultat sérieux doit être refaisable.

Conserve :

- version des données ;
- paramètres ;
- code ;
- seed si simulation ;
- environnement ;
- date de lancement ;
- sortie brute.

Une capture d'écran seule n'est pas un laboratoire.
