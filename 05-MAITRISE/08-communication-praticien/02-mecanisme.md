# 02 : MÉCANISME : NOTE DE PRATICIEN

Une bonne note ne cherche pas à impressionner. Elle permet à un tiers de comprendre la décision sans reconstruire tout le travail.

```text
thèse
→ preuve
→ risque
→ contre-argument
→ condition d'invalidation
→ action
```
