# 02 : MÉCANISME : VALIDATION

Tester N variantes augmente la probabilité de trouver un gagnant par hasard.

```text
1 test → risque de faux positif
1000 tests → risque multiplié
```

Les outils comme **multiple testing (correction des essais multiples)**, White Reality Check, SPA, Deflated Sharpe Ratio et Probability of Backtest Overfitting traitent différentes facettes du problème.
