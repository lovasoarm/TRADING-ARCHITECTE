# 02 — MÉCANISME : RISQUE MODÈLE

## CARTE VISUELLE

```text
IDÉE
  ↓
EXPOSITION
  ↓
SIZING
  ↓
LEVIER
  ↓
SLIPPAGE / GAP / FRAIS
  ↓
PERTE RÉELLE
  ↓
CAPITAL RESTANT
```

Un modèle est un paquet d'hypothèses.

```text
hypothèses
 + données
 + paramètres
 + règles de décision
 = modèle
```

Le risque modèle apparaît quand une de ces pièces cesse d'être valide ou quand on oublie qu'elle existait.
